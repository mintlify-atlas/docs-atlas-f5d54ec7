Old Windows is a fully interactive, browser-based desktop environment that reimagines the Windows 98 aesthetic as a developer portfolio. Every section of the portfolio lives inside a resizable, draggable window — from your work history in a Notepad clone to your projects displayed in a Windows Explorer-style file manager. The entire experience is built on React with Framer Motion driving the window animations and a custom CSS system for the authentic beveled Win98 borders, pixel fonts, and CRT scanline overlay.

## Quick Look

<Steps>
  <Step title="Clone and install">
    ```bash
    git clone https://github.com/apursley2012/old-windows.git
    cd old-windows
    npm install
    ```
  </Step>
  <Step title="Start the dev server">
    ```bash
    npm run dev
    ```
    Open [http://localhost:5173](http://localhost:5173) — the Windows 98 desktop loads immediately.
  </Step>
  <Step title="Edit your apps">
    Open `config/apps.js` and replace the placeholder content in each app component with your own portfolio content.
  </Step>
  <Step title="Deploy">
    ```bash
    npm run build
    ```
    The `dist/` output is a static site — deploy it to GitHub Pages, Netlify, Vercel, or any static host.
  </Step>
</Steps>
